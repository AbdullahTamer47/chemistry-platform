# 🧪 منصة كيمياوي | د. زياد رمزي عياد (Z.R.A Chemistry Platform)

منصة تعليمية متكاملة واحترافية لمادة الكيمياء للمرحلة الثانوية العامة (أولى، ثانية، وثالثة ثانوي)، مصممة وفق أحدث معايير تجربة المستخدم (UX/UI) والأمان التعليمي المتقدم.

---

## 🌟 أبرز مميزات المنصة

### 1. 🎓 كتالوج الكورسات والباقات الموحد (Unified Catalog & Curriculum Scope)
- شمول كامل للكورسات الشهرية، باقات الـ 3 شهور، وباقات الترم الشاملة تحت مظلة واحدة (`#/courses`).
- نظام **نطاق المحتوى المنهجي**: المحتوى المتاح للطالب يظل مفتوحاً طوال العام الدراسي حتى امتحانات الثانوية العامة بدون تاريخ انتهاء صلاحية.
- فلاتر فورية للمراحل الدراسية ونوع المحتوى (شهري، 3 شهور، ترم كامل، سنة دراسية).
- شارات توضيحية لنسب التوفير والخصومات (`original_price` vs `price`).

### 2. 💳 محفظة إلكترونية وشحن فوري ذكي (Fawry Instant Pay)
- شحن فوري وتوليد كود مرجعي مكون من 8-16 رقماً مع باركود فوري صالح عبر جميع ماكينات فوري ومنافذ الدفع.
- محاكاة دفع تجريبية فورية، مع دعم تحويلات فودافون كاش وإنستاباي مع رفع إيصالات التحويل ومراجعتها.

### 3. 🎯 تدريب علاجي ذكي على الأخطاء (Adaptive Mistake Quiz)
- نظام ذكي يفرز جميع الأسئلة التي أخطأ فيها الطالب في الامتحانات السابقة ويولد اختباراً علاجياً مخصصاً بضغطة زر لتقوية نقاط الضعف فوراً.

### 4. 📜 شهادات تقدير رقمية معتمدة (Digital Certificates & Badges)
- استخراج شهادات تفوق تلقائية عند اجتياز الامتحانات الشاملة بنسبة تفوق (≥ 85%).
- إمكانية استعراض الشهادة، طباعتها أو تحميلها كـ PDF مع كود تحقق مشفر (QR/Verification Code).

### 5. 📍 دليل منافذ المذكرات والمكتبات المعتمدة (Interactive Store Locator)
- خريطة ودليل تفاعلي مقسم حسب المحافظات (القاهرة، الجيزة، الإسكندرية، الدقهلية، الغربية، وغيرها) يوضح عناوين المكتبات المعتمدة وأرقام التواصل.

### 6. 🛡️ أمان تعليمي متقدم وحماية المحتوى (Anti-Piracy & Security)
- إدارة ذكية لأجهزة الطلاب (FIFO Device Rotation) لمنع مشاركة الحسابات على مجموعات مع ضمان عدم قفل حساب الطالب المشروع.
- منع تسريب الفيديوهات: علامة مائية متحركة (Watermark) برقم هاتف الطالب واسمه، وحماية روابط الفيديو خلف توكنات موقوتة.
- تصحيح مقالي متقدم للمعلم مع تغذية راجعة صوتية ومكتوبة لكل سؤال.

---

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** Vanilla JavaScript (ES Modules), Custom Responsive CSS Design System (Emerald/Slate Palette), Vite.
- **Backend:** Node.js, Express.js.
- **Database:** SQLite3 (better-sqlite3) with WAL Mode for ultra-fast concurrency.
- **Authentication:** JWT (JSON Web Tokens) with device fingerprinting and bcrypt password hashing.

## 🚀 تشغيل المشروع محلياً (Quick Start)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر وواجهة التطوير:
```bash
npm run dev
```
- خادم التطوير (Vite HMR): `http://localhost:5173`
- الخادم الإنتاجي والـ API: `http://localhost:3000`

### 3. تشغيل الاختبارات:
```bash
npm test
node scratch/test_new_pillars.js
```

### 4. بناء نسخة الإنتاج:
```bash
npm run build
```
