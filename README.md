# 🧪 منصة كيمياوي | د. زياد رمزي عياد (Z.R.A Chemistry Platform)

منصة تعليمية متكاملة واحترافية لمادة الكيمياء للمرحلة الثانوية العامة والإعدادية، مصممة وفق أحدث معايير تجربة المستخدم (UX/UI) والأمان التعليمي المتقدم.

---

## 🌟 أبرز مميزات المنصة

### 1. 🎓 كتالوج الكورسات والباقات الموحد (Unified Catalog & Curriculum Scope)
- شمول كامل للكورسات الشهرية، باقات الـ 3 شهور، وباقات الترم الشاملة تحت مظلة واحدة (`#/courses` و `#/packages`).
- نظام **نطاق المحتوى المنهجي**: المحتوى المتاح للطالب يظل مفتوحاً طوال العام الدراسي حتى امتحانات الثانوية العامة بدون تاريخ انتهاء صلاحية.
- فلاتر فورية للمراحل الدراسية ونوع المحتوى (شهري، 3 شهور، ترم كامل، سنة دراسية).
- شارات توضيحية لنسب التوفير والخصومات (`original_price` vs `price`).

### 2. ⚗️ المختبر الكيميائي التفاعلي الذكي (Interactive Chemistry Lab)
- **حاسبة الكتلة المولية ونسب العناصر**: تحليل الصيغ الكيميائية المعقدة والأقواس وحساب الكتل المولية والنسب المئوية الكتلية.
- **مختبر المعايرة الحجمية**: حل مسائل التعادل والأحماض والقواعد لحظياً بالقانون المنهجي.
- **مستكشف العناصر الانتقالية والجدول الدوري**: عرض التوزيع الإلكتروني، حالات التأكسد، الخصائص المغناطيسية، والأهمية الاقتصادية لعناصر السلسلة الانتقالية الأولى.
- **بنك معادلات الثانوية العامة وبطاقات المراجعة السريعة (Flashcards)**: مراجعة المعادلات وشروط التفاعل وتغيرات الألوان.

### 3. 💳 محفظة إلكترونية وشحن فوري ذكي (Fawry Instant Pay)
- شحن فوري وتوليد كود مرجعي مع باركود صالح عبر ماكينات فوري ومنافذ الدفع.
- دعم تحويلات فودافون كاش وإنستاباي مع رفع إيصالات التحويل ومراجعتها من لوحة المعلم، وتفعيل فوري لأكواد الكروت.

### 4. 🎯 تدريب علاجي ذكي على الأخطاء (Adaptive Mistake Quiz)
- نظام ذكي يفرز جميع الأسئلة التي أخطأ فيها الطالب في الامتحانات السابقة ويولد اختباراً علاجياً مخصصاً بضغطة زر مع تصحيح فوري وشرح تفصيلي.

### 5. 📜 شهادات تقدير رقمية معتمدة مع التحقق المباشر (Digital Certificates)
- استخراج شهادات تفوق تلقائية عند اجتياز الامتحانات بنسبة تفوق (≥ 85%) مع نظام تحقق فوري من صحة الشهادة عبر كود الشهادة المعتمد.

### 6. 📝 ملاحظات الطالب الموقوتة داخل المحاضرات (Timestamped Study Notes)
- إمكانية تدوين ملاحظات شخصية مرتبطة بلحظة زمنية محددة داخل الفيديو والرجوع إليها في أي وقت.

### 7. 📍 دليل منافذ المذكرات والمكتبات المعتمدة (Interactive Store Locator)
- خريطة ودليل تفاعلي مقسم حسب المحافظات يوضح عناوين المكتبات المعتمدة وأرقام التواصل المباشر عبر واتساب.

### 8. 🛡️ أمان تعليمي متقدم وحماية المحتوى (Anti-Piracy & Security)
- إدارة ذكية لأجهزة الطلاب (FIFO Device Rotation) لمنع مشاركة الحسابات مع ضمان عدم قفل حساب الطالب المشروع.
- حماية الفيديوهات بعلامة مائية متحركة (Watermark) برقم هاتف الطالب واسمه، وتوكنات مشاهدة موقوتة.
- تصحيح مقالي متقدم للمعلم مع تغذية راجعة تفصيلية لكل سؤال.

---

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** Vanilla JavaScript (ES Modules), Custom Responsive CSS Design System (Emerald/Slate Palette + Dark Mode), Vite.
- **Backend:** Node.js, Express.js.
- **Database:** SQLite3 (`better-sqlite3` with WebAssembly `sql.js` serverless fallback) + WAL Mode.
- **Authentication:** JWT (JSON Web Tokens) with device fingerprinting and `bcryptjs` password hashing.

## 🚀 تشغيل المشروع محلياً (Quick Start)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر وواجهة التطوير:
```bash
npm run dev
```
- خادم التطوير (Vite HMR): `http://localhost:5173`
- الخادم الإنتاجي والـ API: `http://localhost:3000`

### 3. تشغيل الاختبارات الشاملة:
```bash
npm test
```

### 4. بناء نسخة الإنتاج:
```bash
npm run build
```

## 👥 تهيئة البيانات الأولية

يتم تهيئة المنهج الدراسي والكورسات الافتراضية تلقائياً عند أول تشغيل. لإعادة تهيئة قاعدة البيانات يدوياً في بيئة التطوير، شغّل `npm run seed -- --yes` (يولّد كلمات مرور عشوائية ويطبعها في الكونسول مرة واحدة).
